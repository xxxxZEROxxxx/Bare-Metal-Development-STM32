
# A learning note | reference of stm32 bare metal programming


📗 This repo have the detailed learning note of bare metal stm32 development, its suggested more tobe used as a reference
tool book, as detailed register and functionality of stm32 series being listed in folders (eg GPIO) for convenience of referencing
during development

- Who is this for: someone who have strong understanding in C and basic electronics, even HAL or LL, who want a deeper and more naïve understanding
  in even lower level development

📕 The guide learning plan of this "course" in in file
[baremetal-plan.md](baremetal-plan.md)
where from basic register write to Free RTOS is lined up with in 60 sessions, each sessions cost around 6h

📕Part of learning material are open sourced in this reop, books
- [Bare-Metal Embedded C Programming by Israel Gbati.pdf](material/Bare-Metal%20Embedded%20C%20Programming%20by%20Israel%20Gbati.pdf)
